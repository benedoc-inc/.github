# BeneDoc

We build tools for regulatory compliance.

Our open-source libraries power document processing and machine learning inference in Go — released from work on the BeneDoc platform.

---

## Open Source

### [pdfer](https://github.com/benedoc-inc/pdfer)
Pure Go library for PDF processing with comprehensive XFA (XML Forms Architecture) support. Zero CGO, no external dependencies.

### [xfa-web](https://github.com/benedoc-inc/xfa-web)
XFA PDF form renderer — Go backend with a React/TypeScript frontend. Renders and interacts with XFA-based PDF forms in the browser.

### [onnxer](https://github.com/benedoc-inc/onnxer)
Pure Go binding for ONNX Runtime via [ebitengine/purego](https://github.com/ebitengine/purego) — no CGO required. Run ONNX models in Go without a C toolchain.
